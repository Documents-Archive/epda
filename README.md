# epda
epda nedir? {

*epda, kendi organizasyonumuz için oluşturduğumuz bir paket yöneticisidir. Görevi ise sizin için otomatik olarak kaynak kodlarımızı size kurmayı kolaylaştırmaktır.

*not:bağımlılıklarıda beraberinde kurar.

}
nasıl çalışır? {

*aslında çalışma mantığını oldukça basit tasarladık. Gh aracını kullanarak sisteminize 'depo-liste' deposundaki en yeni depo.txt dosyasını çeker ve onu parse eder, siz ürünü seçtiğinizde otomatik olarak kaynak kodunu ve makefile ını çeker,kaynak kodu derler sisteme tanıtır ve bağımlılıklarını kurar.

}
